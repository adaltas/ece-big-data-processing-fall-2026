# ECE big data processing fall 2026

## Lab and project submission guidelines

Send an email to `joe@adaltas.com` with the following information.

```txt
subject: ECE big data processing Gr-x git repo link
cc: <members of lab or project group>

- Git repo link
- Group(eg, gr-01, gr-02, gr-03, gr-04)
- project/lab member 1, git username
- project/lab member 2, git username
- project/lab member 3, git username
```

Include the lab/project group information in a top level `README.md`. 

```text
- Group(eg, gr-01, gr-02, gr-03, gr-04)
- project/lab member 1, git username
- project/lab member 2, git username
- project/lab member 3, git username
```

**NOTE:** This email and set up only needs to be done one time for the labs, and 1 time when the project is being submitted unless group members change between labs and projects or the repo changes. In the case of group membership changes, include a new email and a subset of group/lab/project information by lab/project.
